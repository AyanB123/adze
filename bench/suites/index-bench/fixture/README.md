# Fixture service

A tiny checked-in codebase for `index-bench`. It is deliberately small
(under 20 files, under 50 KB) so the suite runs in seconds on a laptop
with no container and no network.

The files use distinctive symbol names so each query in
`cases/queries.json` has an unambiguous expected file. The names are
listed in that file, not here, so prose cannot pollute lexical search.
